## 🌟 Overview

A luxury, dark-themed, cinematic personal portfolio engineered to showcase production-grade AI/ML applications, computer vision models, and scalable full-stack web platforms.

### ✨ Key Features

- **Cinematic Dark Aesthetic**: Pure black backdrop (`#000000`), warm bronze and luxury gold accents (`#D4AF37`, `#8C6D4F`), and refined typography (`Bebas Neue`, `Cinzel`, `Montserrat`, `Herr Von Muellerhoff`).
- **Seamless Portrait Lighting**: Multi-directional vignettes that naturally dissolve high-resolution portraits into dark negative space.
- **AST Rotating Insignia**: Custom SVG golden medallion displaying *"AST 2028 • APPARI SRI TEJA • AI/ML & FULL STACK • MVGR"*.
- **Interactive 3D Moment Switcher**: 3D tilt card in the About section enabling interactive exploration of authentic college, campus, and portrait moments.
- **ScrollStack Projects Deck**: GPU-accelerated 3D stacking card physics powered by Lenis smooth scroll showcasing real flagship GitHub projects.
- **Skills Bento Matrix**: Categorized grid covering AI/ML, Full Stack, Databases & Data Science, Programming Foundations, and DevOps/Tools.
- **Interactive Curriculum Vitae**: In-browser modal overlay with clean typography, direct PDF download, and print support.
- **Terminal Dispatch Console**: Modern contact interface with one-click clipboard copying and automated email dispatch formatting.
- **Zero Horizontal Overflow**: Fully responsive layout optimized for mobile (`390px+`), tablets, laptops, and ultra-wide displays.

## 💻 Local Development

### Prerequisites
- Node.js `18.x` or higher
- npm / pnpm / yarn

### Installation
```bash
# Clone repository
git clone https://github.com/sriteja2007/3D-Portfolio.git
cd 3D-Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build
```bash
npm run build
npm run preview
```

## 🌐 Deployment

### Vercel (Recommended)

4. Output Directory: `dist`.
5. Deploy!

1. Connect repository on [Netlify](https://netlify.com).
2. Build Command: `npm run build`.
